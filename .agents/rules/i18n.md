# Bilingual Localization Rule (English & Italian)

All user-facing text in Whisper GUI must support both **English (`en`)** and **Italian (`it`)**.

## Requirements for every feature or UI change

1. **Never hardcode user-facing strings** in widgets, dialogs, status bars, worker progress messages, or exported documents. Use `tr("...")` from `whisper_gui.i18n`.
2. **Update both `"en"` and `"it"` together** in `TRANSLATIONS` inside `src/whisper_gui/i18n.py`, keeping identical keys and `{placeholder}` variables.
3. **Wire live retranslation**: any new UI label, button, tooltip, placeholder, combo item, or menu action must also be updated inside its widget's `retranslate_ui()` method so switching language in Settings updates the whole app immediately without restarting.
4. **Verify parity before finishing**: run `pytest` (specifically `tests/test_i18n.py`), which enforces key parity, placeholder parity, and checks that every `tr(...)` key used in `src/whisper_gui/` exists in both English and Italian.
